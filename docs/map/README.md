# Map interface

Macrostrat's map interface, at [`/map`](/map), is the primary tool for
interacting with our harmonized, multiscale geologic map. It integrates hundreds
of bedrock geologic maps into a single database; as you zoom in and out, the
display shifts between harmonized levels of detail, and clicking the map reveals
the primary data from the source map alongside regional stratigraphy, fossil
collections and literature.

- [Using the map interface](usage.md) — a tour of its capabilities.
- [Changelog](changelog.md) — what changed in each release of the map interface.
- [Map sources](/map/sources) — the geologic maps that make up the compilation.
